### 👨‍💻 About me

Independent electronics developer — I take a device **from idea to finished product**:

- ⚡ **Schematics & PCB** — multilayer boards in Altium Designer, enclosures in Autodesk Inventor
- 🔧 **Prototyping** — component sourcing, assembly, bring-up and debugging on the bench
- 🧠 **Firmware** — C for STM32 / ARM Cortex-M: CAN, RS-485, USB, sensors, power electronics
- 🖥️ **Software** — desktop and web tools for my devices in C# (.NET, WPF, Blazor)

Currently growing toward **high-speed interface design**.
